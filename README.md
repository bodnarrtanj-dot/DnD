# Shadows of the Forgotten: Cult of Kaplos

## 📖 Опис гри

**Shadows of the Forgotten: Cult of Kaplos** — це 2D покрокова кооперативна RPG у темно-фентезійному сетингу, заснована на механіках Dungeons & Dragons. Гра пропонує:

- 🎲 **Система кидків кубиків** (d6, d20) для всіх дій
- 🗺️ **Велика інтерактивна карта світу** з містами, лісами, горами та данжами
- ⚔️ **Покрокова бойова система** з ініціативою, атаками, заклинаннями
- 👥 **Кооператив для 4 гравців** (поки що в розробці)
- 🏰 **Сюжетна лінія** про боротьбу з культом Каплоса

## 🚀 Як запустити гру

### 📥 Вимоги

1. **Godot Engine 4.x** (рекомендується 4.2+)
   - [Завантажити Godot](https://godotengine.org/download)

2. **Операційна система**: Windows, Linux або macOS

### 🎮 Запуск

1. **Клонуйте репозиторій**:
   ```bash
   git clone https://github.com/bodnarrtanj-dot/DnD.git
   cd DnD
   ```

2. **Відкрийте проєкт у Godot**:
   - Запустіть Godot
   - Натисніть "Import" і виберіть файл `project.godot`

3. **Запустіть гру**:
   - Натисніть кнопку "Play" (▶️) у верхньому лівому куті
   - Або натисніть F5

## 🎨 Візуальний стиль

Гра використовує **піксель-арт** у стилі "The Coffin of Andy and Leyley":
- **Розмір пікселів**: 16x16 (тайли), 32x32 (персонажі, монстри)
- **Кольорова палітра**: Темні тони (чорний, сірий, темно-зелений, темно-червоний)
- **Текстура**: Зернистість, ефекти старіння

*Примітка*: Піксель-арт спрайти потрібно додати до папки `assets/sprites/` для повної візуалізації.

## 🎮 Геймплей

### 🌍 Світ

1. **Карта світу**: Гравці переміщуються по великій 2D-карті з різними територіями:
   - Ліси (рух коштує +1 дію)
   - Дороги (рух коштує -1 дію)
   - Міста (точки для відпочинку та квестів)
   - Данжі (вхід до підземелль)

2. **Рух**: Кожен крок вимагає кидка **d6** для визначення відстані:
   - 1-2: 1 клітинка
   - 3-4: 2 клітинки
   - 5-6: 3 клітинки
   - Модифікатори: дорога (+1), ліс (-1), навичка Атлетика (+1)

3. **Випадкові зустрічі** (10% шанс на крок):
   - Бій з монстрами
   - Пастка
   - Зустріч з NPC
   - Знахідка

### ⚔️ Бій

1. **Ініціатива**: Кожен учасник кидає **d20 + модифікатор Спритності**
2. **Атака**: **d20 + бонус атаки** проти класу броні ворога (AC)
3. **Шкода**: Кидок кубика урону зброї + модифікатор характеристики
4. **Критичний влучний**: 20 на d20 = подвійна шкода
5. **Критичний промах**: 1 на d20 = автоматичний промах

### 📜 Квести

Головна сюжетна лінія:
1. **Розслідування культу Каплоса** → Знайти табір культистів
2. **Таємниця Камілгтона** → Дізнатися про плани культу
3. **Печера Каплоса** → Знищити голову культу (Мал'гатхор)
