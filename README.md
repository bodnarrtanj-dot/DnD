# D&D Dark Fantasy RPG - Unity Project

## 📖 Опис проєкту

Це **2D turn-based co-op RPG** у стилі Dungeons & Dragons з **dark fantasy** атмосферою, заснована на вашій карті світу (Kingdom of Kerinmor, Revenhold, Kamiltgon, Cave of Kaplos).

Проєкт створений для **Unity 2022 LTS** і підтримує:
- 🎮 **2D рух по карті** (WASD)
- 🎲 **D&D механіки** (кубики d6, d20, модифікатори характеристик)
- ⚔️ **Покроковий бій** з монстрами
- 🗺️ **Карту світу** з вашими локаціями
- 🏰 **Данжі** (Cave of Kaplos як фінальне місце)

---

## 🚀 Як запустити проєкт

### 1️⃣ Встановіть Unity Hub
1. Завантажте [Unity Hub](https://unity.com/download)
2. Встановіть **Unity 2022 LTS** (рекомендується для стабільності)
3. Додайте модуль **2D Game Kit** (під час встановлення Unity)

### 2️⃣ Клонуйте або завантажте проєкт

#### 🔹 Якщо ви хочете клонувати через Git:
```bash
cd ~/Desktop
git clone https://github.com/bodnarrtanj-dot/DnD.git
cd DnD
```

#### 🔹 Якщо ви хочете завантажити ZIP:
1. На GitHub перейдіть у репозиторій
2. Натисніть **"Code" → "Download ZIP"**
3. Розпакуйте архів у зручну папку

### 3️⃣ Додайте вашу карту
1. Помістіть ваше зображення карти у папку:
   ```
   DnD/Assets/Resources/Maps/map.png
   ```
   *(Якщо папки `Resources/Maps` немає, створіть її)*

### 4️⃣ Відкрийте проєкт у Unity Hub
1. Запустіть **Unity Hub**
2. Натисніть **"Add"** → оберіть папку `DnD`
3. Натисніть **"Open"**
4. Дочекайтеся, поки Unity завантажить проєкт

### 5️⃣ Налаштуйте сцену
1. У вікні **Project** знайдіть:
   - `Assets/Scenes/MainScene.unity` (подвійний клік для відкриття)
2. Додайте вашу карту на сцену:
   - Перетягніть `map.png` з `Assets/Resources/Maps` на сцену
   - Масштабуйте карту за допомогою миші
3. Додайте гравця:
   - Створіть **2D Object → Sprite → Square**
   - Перейменуйте його на **"Player"**
   - Додайте тег **"Player"**
   - Додайте скрипт **`PlayerController.cs`** (з папки `Assets/Scripts`)
4. Налаштуйте камеру:
   - Виділіть **Main Camera**
   - У **Inspector** змініть **Projection** на **Orthographic**
   - Додайте скрипт **`CameraController.cs`**
   - Встановіть **Size** камери так, щоб було видно всю карту

### 6️⃣ Запустіть гру
- Натисніть **▶️ Play** у верхньому центрі Unity
- **Керування:**
  - **WASD** – рух камери
  - **Пробіл** – кинути d6 (рух гравця)
  - **E** – взаємодія з об'єктами

## 🔧 Налаштування координат локацій

У файлі `WorldMap.cs` ви знайдете масив `LOCATIONS`, де вказано координати для кожної локації у **пікселях від лівого верхнього кута**.

**Приклад:**
```csharp
locations.Add(new Location {
    name = "Kingdom of Kerinmor",
    description = "Столиця імперії.",
    type = LocationType.City,
    position = new Vector2(200, 120) // Координати у пікселях
});
```

**Як дізнатися координати?**
1. Відкрийте ваше зображення в **Paint** або **Preview** (на Mac)
2. Наведіть курсор на потрібне місце
3. Координати з'являться внизу вікна

## 🐛 Виправлення поширених помилок

### ❌ Помилка: "Project is not valid"
**Рішення:** Переконайтеся, що ви відкриваєте **папку `DnD`**, а не файли всередині неї.

### ❌ Помилка: "Missing Scripts"
**Рішення:** Unity іноді видаляє посилання на скрипти. Просто перетягніть скрипти з папки `Assets/Scripts` на об'єкти на сцені.

### ❌ Помилка: "No Unity Editor installed"
**Рішення:** Встановіть **Unity 2022 LTS** через Unity Hub.

### ❌ Карта не відображається
**Рішення:**
1. Переконайтеся, що файл називається **`map.png`**
2. Переконайтеся, що він знаходиться у **`Assets/Resources/Maps/map.png`**
3. У **Inspector** для об'єкта з картою переконайтеся, що **Texture Type** = **Sprite (2D and UI)**
