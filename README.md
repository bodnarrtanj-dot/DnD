# D&D Dark Fantasy RPG - Unity Project

## 🎮 Готовий до запуску проєкт!

**Цей проєкт уже налаштований для роботи в Unity.**
Просто **клонуйте репозиторій, відкривайте в Unity Hub, і гра працюватиме!**

---

## 🚀 Як запустити за 3 кроки:

### 1️⃣ Клонуйте репозиторій
```bash
cd ~/Desktop
git clone https://github.com/bodnarrtanj-dot/DnD.git
```

### 2️⃣ Відкрийте проєкт у Unity Hub
1. Запустіть **Unity Hub**
2. Натисніть **"Add"** → оберіть папку `~/Desktop/DnD`
3. Натисніть **"Open"**
4. **Дочекайтеся**, поки Unity завантажить проєкт

### 3️⃣ Запустіть гру
- Натисніть **▶️ Play** у верхньому центрі Unity
- **Гра працює!** 🎉

## 📁 Структура проєкту:
```
DnD/
├── Assets/
│   ├── Scripts/               # C# скрипти
│   │   ├── PlayerController.cs  # Керування гравцем
│   │   ├── DiceSystem.cs        # Система кубиків (d6, d20)
│   │   ├── CombatSystem.cs      # Бойова система
│   │   ├── WorldMap.cs          # Карта світу з вашими локаціями
│   │   ├── GameManager.cs       # Керування станом гри
│   │   ├── CameraController.cs  # Камера
│   │   ├── Enemy.cs            # Клас ворога
│   │   └── Character.cs        # Клас персонажа
│   ├── Scenes/                # Сцени
│   │   └── MainScene.unity     # ✅ Готова сцена з налаштованими об'єктами
│   ├── Resources/              # Ресурси
│   │   └── Maps/               # Карти
│   │       └── map.png         # ✅ Ваша карта вже додана!
│   ├── Prefabs/               # Заготовки
│   └── Plugins/                # Плагіни
└── README.md                  # Ця інструкція
```

## ⚠️ Важливо:
1. **Координати локацій** у `WorldMap.cs` вказано в пікселях.
   - **Потрібно підкорегувати** їх під ваше зображення!
   - Відкрийте `map.png` у **Preview** (Mac) → наведіть курсор на локацію → подивіться координати внизу.

2. **Якщо карта не відображається**:
   - У **Inspector** для `map.png`:
     - **Texture Type:** `Sprite (2D and UI)`
     - **Mesh Type:** `Full Rect`

## 🔧 Виправлення поширених помилок:

### ❌ Помилка: "The referenced script is missing"
**Рішення:**
1. Видаліть скрипт з об'єкта
2. Перетягніть скрипт знову з папки `Assets/Scripts`

### ❌ Помилка: "No Unity Editor installed"
**Рішення:** Встановіть **Unity 2022 LTS** або **Unity 6** через Unity Hub.

### ❌ Помилка: "Project is not valid"
**Рішення:** Переконайтеся, що ви відкриваєте **папку `DnD`**, а не файли всередині неї.
